## 📁 File Naming Convention

Each solution file is named using the LeetCode problem number and a short slug:

```
<problem_number>_<problem_slug>.py
```

**Example:**

```
arrays_and_hashing/
├── 0001_two_sum.py
├── 0049_group_anagrams.py
└── 0217_contains_duplicate.py
```
